# Keuangan Almer

Aplikasi catatan uang masuk dan investasi yang aku pakai sendiri, supaya tidak perlu hitung manual berapa yang harus diinvestasikan.

**Coba langsung: https://almertamim05012009-cell.github.io/Keuangan-Almer/**

Bisa dicoba tanpa login, datanya tersimpan di perangkat kamu. Kalau mau datanya tersimpan di akun dan muncul di HP maupun komputer, masuk dengan Google.

## Cara kerjanya

Uang yang masuk dicatat ke tas atau ke bank. Dari total uang yang didapat, aplikasi menghitung berapa yang harus diinvestasikan. Persennya bisa kamu atur sendiri. Bawaannya 10%, lalu 20% kalau totalnya sudah Rp 500.000. Begitu investasinya sudah sebesar itu, hitungan mulai lagi dari nol.

## Fitur

- Catatan pemasukan ke tas, pemasukan ke bank, pindah dari tas ke bank, dan investasi
- Target tabungan, lengkap dengan grafik dan ringkasan per bulan
- Cadangan data lewat file CSV
- Tombol untuk menyembunyikan angka
- Tampilan terang atau gelap sesuai pengaturan perangkat

## Dibuat dengan

HTML, CSS, dan JavaScript tanpa framework, semuanya di satu file. Login dan penyimpanan data pakai Firebase, dan halamannya dihosting di GitHub Pages. Data tiap akun terpisah.
